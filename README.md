# 🌾 Vườn Chín Vạn Mẫu (Ninety Thousand Acres — Pixel Farm)

Game web pixel nông trại lấy cảm hứng từ **Ninety Thousand Acres**. Toàn bộ nằm trong một file `index.html` — không cần cài đặt, không cần build.

## ▶️ Chơi

Mở file `index.html` bằng trình duyệt, hoặc bật GitHub Pages:

- `Settings → Pages → Source: Deploy from a branch → main / (root) → Save`
- Game sẽ chạy tại `https://nguyenngu510.github.io/ninetythounsandacres/`

## 🎮 Cách chơi

| Công cụ | Phím | Chức năng |
|---|---|---|
| ⛏️ Cuốc | `1` | Cày luống đất |
| 🌱 Gieo | `2` | Trồng hạt đã chọn |
| 💧 Tưới | `3` | Tưới nước cho cây |
| 🧺 Thu | `4` | Thu hoạch cây chín |
| 🐓 Chăn | `5` | Thu trứng / sữa |
| 🛒 Cửa hàng | `E` | Mua hạt giống, mở khóa cây mới, nâng cấp |

- Cây héo nếu quên tưới → giá bán giảm 40%
- Trời mưa 🌧️ tưới tự động toàn bộ luống
- Năng lượng ⚡ hồi đầy mỗi sáng
- Tiến trình tự lưu vào trình duyệt (localStorage)
